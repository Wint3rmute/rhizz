# 0001: Rhizome v0.6 Baseline

- **Status:** accepted
- **Author:** @wint3rmute
- **Created:** 2026.10.18

## Motivation

Until now, the Rhizome spec development has been chaotic, driven by ad-hoc
prototyping needs. This proposal marks the creation of tag `0.6`, which
will establish the first baseline of the Rhizome spec. Starting from `0.6`,
changes to Rhizome spec will follow the proposal-based flow.
