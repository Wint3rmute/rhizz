# E002 — Undefined component in connection

A connection's `from` or `to` attribute references a component label that does
not exist as a sibling in the current scope. This also fires when the `from` or
`to` attribute is missing entirely.

## Example (error)

```hcl
system "drone" {
  component "motor" {
    description = "Brushless motor"
  }

  connection "power-link" {
    from = "battery"
    to   = "motor"
  }
}
```

Here `"battery"` is not defined as a sibling component.

## Fix

Define the missing component, or correct the label to match an existing one.

```hcl
system "drone" {
  component "battery" {
    description = "LiPo battery pack"
  }
  component "motor" {
    description = "Brushless motor"
  }

  connection "power-link" {
    from = "battery"
    to   = "motor"
  }
}
```
