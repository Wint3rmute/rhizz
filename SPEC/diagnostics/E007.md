# E007 — Field missing required `type` attribute

A `field` block inside a `message` does not have the required `type` attribute.
Every field must declare its data type.

## Example (error)

```hcl
system "drone" {
  component "gps" {
    port "nmea" {
      message "position" {
        field "latitude" {
          description = "Latitude in degrees"
        }
      }
    }
  }
}
```

## Fix

Add a `type` attribute to the field.

```hcl
system "drone" {
  component "gps" {
    port "nmea" {
      message "position" {
        field "latitude" {
          type        = "float64"
          description = "Latitude in degrees"
        }
      }
    }
  }
}
```
