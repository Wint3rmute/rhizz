# E005 — Leaf component has children

A component marked `leaf = true` contains child `component` or `connection`
blocks. Leaf components are atomic — they cannot be decomposed further.

## Example (error)

```hcl
system "drone" {
  component "motor" {
    leaf = true

    component "coil" {
      description = "Motor coil"
    }
  }
}
```

## Fix

Either remove the `leaf = true` attribute to allow decomposition, or remove
the child blocks.

```hcl
system "drone" {
  component "motor" {
    leaf        = true
    description = "Brushless motor — atomic unit"
  }
}
```
