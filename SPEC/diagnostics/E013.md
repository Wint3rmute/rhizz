# E013 — Circular `source` chain

Following the `source` references starting from a component eventually leads
back to the same component, forming a cycle. A component cannot (directly or
indirectly) be its own definition.

## Example (error)

```hcl
component "a" {
  source = "b"
}

component "b" {
  source = "a"
}
```

## Fix

Break the cycle. Ensure that `source` references form a directed acyclic graph
(or, more commonly, that each component references a single concrete top-level
definition with no further `source` attributes).

```hcl
component "a" {
  source = "base-a"
}

component "base-a" {
  description = "Concrete definition of a"
}
```
