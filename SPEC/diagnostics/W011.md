# W011 — Port has no messages

A `port` block contains no `message` children. Ports without messages provide
connection-point structure but no protocol schema information, which limits the
usefulness of the model for documentation and scoring.

## Example (warning)

```hcl
system "drone" {
  component "sensor" {
    port "data" {
      protocol = "I2C"
      role     = "provider"
    }
  }
}
```

`sensor:data` has no messages defined.

## Fix

Add at least one `message` block describing the data exchanged over this port.

```hcl
  component "sensor" {
    port "data" {
      protocol = "I2C"
      role     = "provider"

      message "reading" {
        description = "Periodic sensor reading"
        field "value" { type = "float64"; unit = "m/s²" }
      }
    }
  }
```
