# W011 — Protocol has no messages

A `protocol` block contains no `message` children. Protocols without messages provide
protocol metadata but no payload schema information, which limits the usefulness of
the model for documentation and scoring.

## Example (warning)

```hcl
protocol "i2c-sensor" {
  description = "I2C sensor interface"
  roles       = ["provider", "consumer"]
}
```

`protocol "i2c-sensor"` has no messages defined.

## Fix

Add at least one `message` block describing the data exchanged over this protocol.

```hcl
protocol "i2c-sensor" {
  description = "I2C sensor interface"
  roles       = ["provider", "consumer"]

  message "reading" {
    description = "Periodic sensor reading"
    field "value" { type = "float64"; unit = "m/s²" }
  }
}
```
