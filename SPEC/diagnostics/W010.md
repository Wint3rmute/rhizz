# W010 — Unused port

A port is defined on a component but is not referenced by the `from` or `to`
attribute of any connection (using the `comp:port` syntax). The port may be
intentionally reserved for future use, or it may indicate a forgotten
connection.

## Example (warning)

```hcl
system "drone" {
  component "fc" {
    port "spi"  { protocol = "SPI"; role = "consumer" }
    port "uart" { protocol = "UART"; role = "consumer" }
  }
  component "imu" {
    port "spi" { protocol = "SPI"; role = "provider" }
  }

  connection "imu-link" {
    from = "imu:spi"
    to   = "fc:spi"
  }
}
```

`fc:uart` is defined but not referenced by any connection.

## Fix

Wire the port to a connection, or remove it if it is not needed.

```hcl
  component "gps" {
    port "uart" { protocol = "UART"; role = "provider" }
  }

  connection "gps-link" {
    from = "gps:uart"
    to   = "fc:uart"
  }
```
