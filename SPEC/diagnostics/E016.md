# E016 — Diagram file must hold exactly one matching view

A file under `views/` must contain exactly one `view` block, and the view
label must match the filename stem (`views/overview.hcl` must hold
`view "overview"`). A root-level `views.hcl` holding multiple views gets the
same treatment: it cannot pass validation as-is and must be split into one
file per view under `views/`.

## Example (error): zero view blocks

```hcl
# views/empty.hcl — no view block at all
project {
  name = "demo"
}
```

## Example (error): two view blocks in one file

```hcl
# views/combined.hcl — two views in one file
view "a" {
  system = "demo"
}

view "b" {
  system = "demo"
}
```

## Example (error): label does not match filename

```hcl
# views/overview.hcl — label must be "overview"
view "other" {
  system = "demo"
}
```

## Fix

Split each view into its own file under `views/`, named after the view
label, with exactly one `view` block per file.

```hcl
# views/overview.hcl
view "overview" {
  system = "demo"
}
```
