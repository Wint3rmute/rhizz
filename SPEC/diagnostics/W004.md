# W004 — Missing full_name

**Warning level:** Component.

An entity (system, component, connection, or message) has no `full_name`
attribute. Full names are important for documentation and readability.

For components, the missing-full_name check applies to **definitions only**
(`component "<label>" { ... }`) — an instance clones its definition's body,
so the defect is reported once on the definition, never duplicated
per instance.

## Example (warning)

```hcl
component "motor" {
}
```

`motor` (a definition) has no `full_name`.

## Fix

Add a `full_name` attribute.

```hcl
component "motor" {
  full_name = "Brushless DC motor driving one propeller"
}
```
