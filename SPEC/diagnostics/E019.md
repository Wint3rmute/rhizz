# E019 — Leaf protocol with `realized_by` (Not yet implemented)

A connection whose protocol is declared `leaf = true` also declares
`realized_by`. A leaf protocol needs no further realization, so the two
declarations express conflicting modeling intentions.

## Example (error)

```hcl
protocol "ip" {
  leaf = true
}

system "banking" {
  connection "ip-packet" {
    from        = "bank-a/ip"
    to          = "bank-b/ip"
    realized_by = ["ethernet-frame"]  # Error: "ip" is a leaf protocol
  }
}
```

## Fix

Remove `realized_by`, or set `leaf = false` on the protocol if the connection
is meant to be decomposed further.

```hcl
system "banking" {
  connection "ip-packet" {
    from = "bank-a/ip"
    to   = "bank-b/ip"
  }
}
```
