# E003 — Undefined connection in `encapsulates`

A connection's `encapsulates` list references a sibling connection label that
does not exist in the current scope.

## Example (error)

```hcl
system "drone" {
  component "fc"    { description = "Flight controller" }
  component "motor" { description = "Motor" }

  connection "control-link" {
    from         = "fc"
    to           = "motor"
    encapsulates = ["power-bus"]
  }
}
```

Here `"power-bus"` is not defined as a sibling connection.

## Fix

Define the referenced connection, or remove it from the `encapsulates` list.

```hcl
system "drone" {
  component "fc"    { description = "Flight controller" }
  component "motor" { description = "Motor" }

  connection "power-bus" {
    from = "fc"
    to   = "motor"
  }

  connection "control-link" {
    from         = "fc"
    to           = "motor"
    encapsulates = ["power-bus"]
  }
}
```
