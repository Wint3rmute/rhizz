# E003 — Connection endpoint names a port path

A connection `from`/`to` value names a port path such as `comp/port`. The path resolves to a component holding a port, and the final segment names that port.

## Example (error)

```hcl
system "drone" {
  component "sensor" {
    port "i2c" {
      protocol = "i2c"
      role     = "provider"
    }
  }
  component "fc" {
    port "i2c" {
      protocol = "i2c"
      role     = "consumer"
    }
  }

  connection "sensor-link" {
    from = "sensor"
    to   = "fc/i2c"
  }
}
```

Here `from` names a component without naming one of its ports.

## Fix

Name a port on the component in the endpoint.

```hcl
  connection "sensor-link" {
    from = "sensor/i2c"
    to   = "fc/i2c"
  }
```
