# W009 — Incompatible port roles

Both sides of a connection are typed (`comp:port`) and both ports have roles,
but the role combination is ambiguous or invalid. Valid pairs are
`provider`↔`consumer` and `peer`↔`peer`.

## Example (warning)

```hcl
system "drone" {
  component "sensor-a" {
    port "out" { role = "provider" }
  }
  component "sensor-b" {
    port "out" { role = "provider" }
  }

  connection "sensor-link" {
    from = "sensor-a:out"
    to   = "sensor-b:out"
  }
}
```

Both ports are `provider` — there is no consumer, so direction is ambiguous.

## Fix

Assign compatible roles: one `provider` and one `consumer`, or both `peer`.

```hcl
  component "sensor-b" {
    port "in" { role = "consumer" }
  }

  connection "sensor-link" {
    from = "sensor-a:out"
    to   = "sensor-b:in"
  }
```
