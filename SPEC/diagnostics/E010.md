# E010 — Undefined port in `comp:port` reference

A connection references a component using the typed `comp:port` syntax, and the
component exists, but it does not have a port with the given name.

## Example (error)

```hcl
system "drone" {
  component "sensor" {
    port "i2c" {
      protocol = "I2C"
      role     = "provider"
    }
  }
  component "fc" {
    port "i2c" {
      protocol = "I2C"
      role     = "consumer"
    }
  }

  connection "sensor-link" {
    from = "sensor:spi"
    to   = "fc:i2c"
  }
}
```

Here `sensor` has a port named `"i2c"` but the connection references `"spi"`.

## Fix

Use a port name that exists on the component.

```hcl
  connection "sensor-link" {
    from = "sensor:i2c"
    to   = "fc:i2c"
  }
```
