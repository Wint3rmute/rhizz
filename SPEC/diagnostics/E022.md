# E022 — Proxy-port exclusivity violated

An inferred (proxy) port breaks its 1-to-1 shape: it appears as the
self-endpoint in zero or more than one connection inside its owner (D1), its
delegation target appears in another internal connection (D2), it lives on a
`leaf = true` component, or it lacks `external = true`.

## Example (error)

```hcl
component "weather-service" {
  port "api" { external = true }

  instance "proxy-a" { source = "reverse-proxy" }
  instance "proxy-b" { source = "reverse-proxy" }

  connection "api-a" {
    from = "./api"
    to   = "proxy-a/http"
  }

  connection "api-b" {
    from = "./api"  # Error: second delegation for the same outer port (fan-out)
    to   = "proxy-b/http"
  }
}
```

## Fix

Give the outer port exactly one delegation edge. Model fan-out with behavior
(e.g. a load-balancer) explicitly: a Full Port with declared `protocol`/`role`
plus ordinary assembly wiring, never via omission. Ensure the target appears in
no other internal connection, the owner is non-leaf, and the outer port sets
`external = true`.
