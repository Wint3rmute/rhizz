# W007 — Mixed typed and bare connection endpoints

One side of a connection uses the typed `comp/port` syntax while the other side
uses a bare component label. This means port-level validation (protocol
matching, role checking) can only be performed on one side.

## Example (warning)

```hcl
system "drone" {
  component "sensor" {
    port "i2c" { protocol = "I2C"; role = "provider" }
  }
  component "fc" {
    description = "Flight controller"
  }

  connection "sensor-link" {
    from = "sensor/i2c"
    to   = "fc"
  }
}
```

`from` is typed (`sensor/i2c`) but `to` is bare (`fc`).

## Fix

Add a port to the other component and use the typed syntax on both sides.

```hcl
  component "fc" {
    description = "Flight controller"
    port "i2c" { protocol = "I2C"; role = "consumer" }
  }

  connection "sensor-link" {
    from = "sensor/i2c"
    to   = "fc/i2c"
  }
```
