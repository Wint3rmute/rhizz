# E018 — Cycle in `realized_by`

Connections form a cycle through `realized_by` references, including a
connection that lists itself. Recursive completeness is undefined for a cycle.
Each cycle is reported once, with the connections on it named in the message.

## Example (error)

```hcl
system "banking" {
  connection "fund-transfer" {
    from        = "bank-a/payment"
    to          = "bank-b/payment"
    realized_by = ["http-request"]
  }

  connection "http-request" {
    from        = "bank-a/http"
    to          = "bank-b/http"
    realized_by = ["fund-transfer"]  # Error: closes the cycle
  }
}
```

## Fix

Realization is top-down: only the higher-level connection lists the connections
that realize it. Remove the back reference.

```hcl
system "banking" {
  connection "fund-transfer" {
    from        = "bank-a/payment"
    to          = "bank-b/payment"
    realized_by = ["http-request"]
  }

  connection "http-request" {
    from = "bank-a/http"
    to   = "bank-b/http"
  }
}
```
