# W005 — Self-connection

A connection's `from` and `to` attributes point to the same component. While
not always wrong, this is usually a mistake — connections typically wire two
distinct components together.

## Example (warning)

```hcl
system "drone" {
  component "fc" { description = "Flight controller" }

  connection "loopback" {
    from = "fc"
    to   = "fc"
  }
}
```

## Fix

If the self-connection is intentional, no action is needed. Otherwise, correct
the `from` or `to` label.

```hcl
system "drone" {
  component "fc"     { description = "Flight controller" }
  component "logger" { description = "Flight data logger" }

  connection "log-link" {
    from = "fc"
    to   = "logger"
  }
}
```
