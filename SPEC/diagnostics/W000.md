# W000 — General frontend warning

Non-blocking warning emitted by a frontend (CLI, GUI) for conditions that don't
correspond to a specific model diagnostic. Used as an escape hatch — for
example, when live-reload is unavailable or an optional feature is degraded.

## Example (warning)

This warning is not triggered by HCL content. It is emitted programmatically
by frontends for runtime conditions.

```text
W000: live-reload is not available — install `inotifywait` for automatic rebuilds
```

## Fix

Address the condition described in the warning message, or ignore it if the
degraded functionality is acceptable.
