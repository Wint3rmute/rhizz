# W002 — Message has no fields

A `message` block contains no `field` children. Messages without fields provide
no protocol schema information.

## Example (warning)

```hcl
system "drone" {
  component "sensor" {
    port "data" {
      message "reading" {
        description = "Sensor reading"
      }
    }
  }
}
```

## Fix

Add at least one `field` block to describe the message schema.

```hcl
system "drone" {
  component "sensor" {
    port "data" {
      message "reading" {
        description = "Sensor reading"
        field "value" {
          type = "float64"
          unit = "m/s²"
        }
      }
    }
  }
}
```
