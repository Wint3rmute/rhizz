# E004 — Circular encapsulation chain

Two or more connections form a cycle through their `encapsulates` references.
Connection A encapsulates B, and B (directly or transitively) encapsulates A.

## Example (error)

```hcl
system "drone" {
  component "fc"    { full_name = "Flight controller" }
  component "motor" { full_name = "Motor" }

  connection "link-a" {
    from         = "fc"
    to           = "motor"
    encapsulates = ["link-b"]
  }

  connection "link-b" {
    from         = "fc"
    to           = "motor"
    encapsulates = ["link-a"]
  }
}
```

## Fix

Break the cycle by removing one of the `encapsulates` references.

```hcl
system "drone" {
  component "fc"    { full_name = "Flight controller" }
  component "motor" { full_name = "Motor" }

  connection "link-a" {
    from = "fc"
    to   = "motor"
  }

  connection "link-b" {
    from         = "fc"
    to           = "motor"
    encapsulates = ["link-a"]
  }
}
```
