# E004 — Invalid block label

A block label is empty or contains `/`. `/` is reserved as the path
separator (`SPEC.md` §3): a label containing it can never resolve as a single
path segment, and it would collide with projected port names such as
`B/input`, which are view-local derivations, not real labels.

## Example (error)

```hcl
component "motor/driver" {
  full_name = "Motor driver"
}
```

Here the component label contains `/`, so no `instance` `source`, port path,
or view node path can name it unambiguously.

## Fix

Use a label without `/` (and non-empty). Dashes and underscores are the
conventional separators:

```hcl
component "motor-driver" {
  full_name = "Motor driver"
}
```
