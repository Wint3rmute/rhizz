# W006 — Level decreases relative to parent

A component or connection has a `level` value that is lower than its parent's
level. Since `level` represents abstraction depth, a child should normally have
a level equal to or greater than its parent. A decrease is likely a typo.

## Example (warning)

```hcl
system "drone" {
  level = 0

  component "fc" {
    level = 2

    component "mcu" {
      level = 1
    }
  }
}
```

`mcu` has level 1, which is less than its parent `fc` at level 2.

## Fix

Set the child's level to be at least the parent's level.

```hcl
    component "mcu" {
      level = 3
    }
```
