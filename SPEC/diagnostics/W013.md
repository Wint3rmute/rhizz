# W013 — Port role not permitted by protocol (Not yet implemented)

> **Note**: Role mismatch against protocol `roles` is now enforced as a blocking error `E009` during resolution. More complex protocol contract validation will be implemented later under this diagnostic code.

A port references a top-level `protocol` that restricts permitted roles via its
`roles` attribute, but the port declares a `role` not present in that list.

This is emitted as a warning to support gradual and exploratory specification
while alerting the architect to an interface contract mismatch.

## Example (warning)

```hcl
protocol "serial-bus" {
  roles = ["provider", "consumer"]
}

system "drone" {
  component "controller" {
    port "bus" {
      protocol = "serial-bus"
      role     = "peer"       # Warning: "peer" is not in ["provider", "consumer"]
    }
  }
}
```

## Fix

Change the port's role to one allowed by the protocol, or update the protocol's
`roles` list to include the role.

```hcl
  component "controller" {
    port "bus" {
      protocol = "serial-bus"
      role     = "provider"
    }
  }
```
