# E014 — `source` references undefined top-level component

A component uses the `source` attribute to reference a top-level component by
label, but no top-level `component` block with that label exists in the project.

## Example (error)

```hcl
system "drone" {
  component "imu" {
    source = "inertial-measurement-unit"   # no such top-level component
  }
}
```

## Fix

Define the missing top-level component, or correct the label to match an
existing one.

```hcl
component "inertial-measurement-unit" {
  description = "6-DOF IMU"
  leaf        = true
}

system "drone" {
  component "imu" {
    source = "inertial-measurement-unit"
  }
}
```
