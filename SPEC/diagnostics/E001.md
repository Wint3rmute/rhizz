# E001 — Duplicate label

Two blocks of the same type share the same label within a single scope. This
applies to systems, components, connections, ports, messages, and fields.

Connections have one extra rule: a connection name must be unique within a
whole system, not just within its declaring scope. Each instance clones the
connections of its definition, so two instances of one definition share
their connection names legitimately (the copies are one connection for
view hiding and the sidebar). But two *different* declarations — two
component definitions, or a system and a component — using the same
connection name in one system is ambiguous for `connection "name"` view
blocks (which are keyed by name) and is rejected, naming both declarations.

## Example (error)

```hcl
system "drone" {
  component "motor" {
    full_name = "Left motor"
  }
  component "motor" {
    full_name = "Right motor"
  }
}
```

## Fix

Rename one of the blocks to a unique label within that scope.

```hcl
system "drone" {
  component "motor-left" {
    full_name = "Left motor"
  }
  component "motor-right" {
    full_name = "Right motor"
  }
}
```
