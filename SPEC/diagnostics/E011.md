# E011 — Undefined component in `comp:port` reference

A connection references a component using the typed `comp:port` syntax, but the
component label does not exist as a sibling in the current scope.

## Example (error)

```hcl
system "drone" {
  component "fc" {
    port "spi" {
      protocol = "SPI"
      role     = "consumer"
    }
  }

  connection "sensor-link" {
    from = "imu:spi"
    to   = "fc:spi"
  }
}
```

Here `"imu"` is not defined as a sibling component.

## Fix

Define the missing component, or correct the label.

```hcl
system "drone" {
  component "imu" {
    description = "Inertial measurement unit"
    port "spi" {
      protocol = "SPI"
      role     = "provider"
    }
  }
  component "fc" {
    port "spi" {
      protocol = "SPI"
      role     = "consumer"
    }
  }

  connection "sensor-link" {
    from = "imu:spi"
    to   = "fc:spi"
  }
}
```
