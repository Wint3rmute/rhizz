# E011 — Undefined component in path reference

A connection references a component using path syntax (e.g. `comp/port`), but the
component label does not exist in the referenced scope.

## Example (error)

```hcl
system "drone" {
  component "fc" {
    port "spi" {
      protocol = "SPI"
      role     = "consumer"
    }
  }

  connection "sensor-link" {
    from = "imu/spi"
    to   = "fc/spi"
  }
}
```

Here `"imu"` is not defined as a component.

## Fix

Define the missing component, or correct the label/path.

```hcl
system "drone" {
  component "imu" {
    description = "Inertial measurement unit"
    port "spi" {
      protocol = "SPI"
      role     = "provider"
    }
  }
  component "fc" {
    port "spi" {
      protocol = "SPI"
      role     = "consumer"
    }
  }

  connection "sensor-link" {
    from = "imu/spi"
    to   = "fc/spi"
  }
}
```
