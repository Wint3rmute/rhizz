# W021 — Protocol cannot carry the realized protocol (Not yet implemented)

**Warning level:** Architectural.

When connection `A` is realized by connection `B`, the protocol of `B` must list
the protocol of `A` in its `encapsulates`. Only directly related pairs are
checked. The check needs both connections to have resolved, declared protocols.

## Example (warning)

```hcl
protocol "fund-transfer" {}
protocol "http" {}  # Warning: does not encapsulate "fund-transfer"

system "banking" {
  connection "fund-transfer" {
    from        = "bank-a/payment"
    to          = "bank-b/payment"
    realized_by = ["http-request"]
  }

  connection "http-request" {
    from = "bank-a/http"
    to   = "bank-b/http"
  }
}
```

## Fix

Declare that the carrying protocol can carry the realized one.

```hcl
protocol "http" {
  encapsulates = ["fund-transfer"]
}
```
