# E015 — Connection declared outside Lowest Common Ancestor

A `connection` block is declared inside a scope (component or system) that is
not an ancestor of both the `from` and `to` endpoints. A connection must be
specified in the Lowest Common Ancestor (LCA) component or `system` enclosing
both endpoints, or an ancestor above it.

## Example (error)

```hcl
system "drone" {
  component "flight-controller" {
    component "mcu" {
      port "spi" { protocol = "spi"; role = "provider"; external = true }
    }

    # Error: 'flight-controller' is not an ancestor of 'imu'.
    # This connection belongs in system "drone" (the LCA of 'mcu' and 'imu').
    connection "spi-bus" {
      from = "mcu/spi"
      to   = "../imu/spi"
    }
  }

  component "imu" {
    port "spi" { protocol = "spi"; role = "consumer"; external = true }
  }
}
```

## Fix

Move the `connection` block up to the Lowest Common Ancestor enclosing both
endpoints (in this case, system `"drone"`), and adjust the relative paths
accordingly.

```hcl
system "drone" {
  component "flight-controller" {
    component "mcu" {
      port "spi" { protocol = "spi"; role = "provider"; external = true }
    }
  }

  component "imu" {
    port "spi" { protocol = "spi"; role = "consumer"; external = true }
  }

  connection "spi-bus" {
    from = "flight-controller/mcu/spi"
    to   = "imu/spi"
  }
}
```
