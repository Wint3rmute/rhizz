# W022 — Undefined protocol in `encapsulates` (Not yet implemented)

**Warning level:** Business.

A protocol's `encapsulates` list names a protocol for which no top-level
`protocol` block is defined. This is the protocol counterpart of `W014`: the
protocol may simply not have been written yet, so the model still compiles. The
entry is ignored by the compatibility check.

## Example (warning)

```hcl
protocol "http" {
  encapsulates = ["fund-transfer"]  # Warning: no protocol "fund-transfer" defined
}
```

## Fix

Define the referenced protocol, or correct any typo in the label.

```hcl
protocol "fund-transfer" {}

protocol "http" {
  encapsulates = ["fund-transfer"]
}
```
