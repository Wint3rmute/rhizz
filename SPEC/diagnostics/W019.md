# W019 — Incomplete connection

**Warning level:** Architectural.

A connection is incomplete: its protocol is undefined, or non-leaf, and it has
no complete realization. A connection is complete when its protocol is a leaf
protocol, or when it has `realized_by` entries and every one of them is itself
complete. A connection whose protocol is undefined is always incomplete.

The warning is reported on every incomplete connection, not only on the root
cause. Its message names the first incomplete connection in the chain, when
there is one.

## Example (warning)

```hcl
protocol "fund-transfer" {}

system "banking" {
  connection "fund-transfer" {
    from = "bank-a/payment"
    to   = "bank-b/payment"
    # Warning: non-leaf protocol, no realized_by
  }
}
```

## Fix

Realize the connection by connections that end in leaf protocols, or mark the
protocol as `leaf = true` if it needs no further decomposition.

```hcl
protocol "fund-transfer" {
  leaf = true
}
```
