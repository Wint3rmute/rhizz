# W020 — Realization outside the component hierarchy (Not yet implemented)

**Warning level:** Architectural.

A realizing connection has an endpoint outside the hierarchy of the connection
it realizes. Its `from` endpoint must be the same component as the parent
connection's `from` endpoint or a descendant of it, and likewise for `to`. The
checks are not swapped, so a realization running in the opposite direction is
reported. They apply at every realization step.

## Example (warning)

```hcl
system "banking" {
  connection "fund-transfer" {
    from        = "bank-a/payment"
    to          = "bank-b/payment"
    realized_by = ["http-request"]
  }

  connection "http-request" {
    from = "bank-b/http"  # Warning: not within bank-a
    to   = "bank-a/http"  # Warning: not within bank-b
  }
}
```

## Fix

Make the realizing connection run between the same components (or their
descendants) as the connection it realizes, in the same direction.

```hcl
  connection "http-request" {
    from = "bank-a/http"
    to   = "bank-b/http"
  }
```
