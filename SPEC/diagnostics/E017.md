# E017 — Unresolved `realized_by` reference (Not yet implemented)

A connection's `realized_by` list contains an entry that does not resolve to a
connection. The last segment of an entry is always a connection label; the
segments before it name a component or system, resolved like the component part
of a `from`/`to` endpoint. A target outside the declaring connection's system
(or top-level definition tree) is also unresolved.

The message names the entry and the scope that was searched.

## Example (error)

```hcl
system "banking" {
  connection "fund-transfer" {
    from        = "bank-a/payment"
    to          = "bank-b/payment"
    realized_by = ["http-request"]  # Error: no connection "http-request" in this scope
  }
}
```

## Fix

Declare the referenced connection, or correct the entry. Use a path when the
target lives in another scope (`"bank-a/http-request"`, `"../uplink"`,
`"/banking/http-request"`).

```hcl
system "banking" {
  connection "fund-transfer" {
    from        = "bank-a/payment"
    to          = "bank-b/payment"
    realized_by = ["http-request"]
  }

  connection "http-request" {
    from = "bank-a/http"
    to   = "bank-b/http"
  }
}
```
