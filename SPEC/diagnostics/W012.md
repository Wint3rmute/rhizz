# W012 — Orphan top-level component

A top-level `component` block is defined at the project level (outside any
`system` block) but is never referenced by any `source` attribute anywhere in
the project. The definition is unused.

## Example (warning)

```hcl
component "reusable-sensor" {
  description = "Generic sensor"
  leaf        = true
}

system "drone" {
  component "imu" {
    description = "Inertial measurement unit"
    leaf        = true
  }
  # "reusable-sensor" is never used via source = "reusable-sensor"
}
```

## Fix

Either reference the top-level component via a `source` attribute inside a
system, or remove the unused definition.

```hcl
system "drone" {
  component "sensor" {
    source = "reusable-sensor"
  }
}
```
