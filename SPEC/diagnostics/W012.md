# W012 — Orphan top-level component or protocol

A top-level `component` or `protocol` block is defined at the project level
(outside any `system` block) but is never referenced anywhere in the project.
The definition is unused.

- For top-level components: never referenced by any `source` attribute in any system.
- For top-level protocols: never referenced by any `port.protocol` attribute in any system or top-level component.

## Example (warning)

```hcl
protocol "unused-protocol" {
  description = "Protocol defined but never referenced by any port"
}

component "reusable-sensor" {
  description = "Generic sensor"
  leaf        = true
}

system "drone" {
  component "imu" {
    description = "Inertial measurement unit"
    leaf        = true
  }
}
```

## Fix

Either reference the top-level component (via `source`) or protocol (via `protocol`), or remove the unused definition.

```hcl
system "drone" {
  component "sensor" {
    source = "reusable-sensor"
  }
}
```
