# E008 — Multiple `project` blocks

More than one `project` block is defined across all source files in the
project. Only a single `project` block is allowed.

## Example (error)

```hcl
# file: project.hcl
project {
  name = "drone-v1"
}

# file: extra.hcl
project {
  name = "drone-v2"
}
```

## Fix

Keep only one `project` block across all `.hcl` files in the project.

```hcl
# file: project.hcl
project {
  name    = "drone-v1"
  version = "1.0.0"
}
```
