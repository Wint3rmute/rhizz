# E006 — View references undefined system

A `view` block's `system` attribute names a system that does not exist in the
project. This also fires when the `system` attribute is missing entirely.

## Example (error)

```hcl
system "drone" {
  component "motor" { description = "Motor" }
}

view "overview" {
  description = "System overview"
  system      = "quadcopter"
}
```

Here the view references `"quadcopter"`, but the only defined system is
`"drone"`.

## Fix

Use a system label that matches a defined `system` block.

```hcl
system "drone" {
  component "motor" { description = "Motor" }
}

view "overview" {
  description = "System overview"
  system      = "drone"
}
```
