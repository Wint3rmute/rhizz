# E020 — Cycle in protocol `encapsulates`

Protocols form a cycle through `encapsulates`. A protocol listing itself counts
as a cycle: it would have to carry itself. Each cycle is reported once, with the
protocol labels on it named in the message.

## Example (error)

```hcl
protocol "http" {
  encapsulates = ["tls"]
}

protocol "tls" {
  encapsulates = ["http"]  # Error: http -> tls -> http
}
```

## Fix

Break the cycle so that `encapsulates` only points from a carrier to the
payload protocols it can carry.

```hcl
protocol "http" {
  encapsulates = ["fund-transfer"]
}

protocol "tls" {
  encapsulates = ["http"]
}
```
