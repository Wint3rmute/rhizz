# E000 — HCL parse failure

The `.hcl` file contains invalid HCL syntax that the parser cannot recover from.
This is also used as an escape hatch for internal structural errors forwarded by
the frontend.

## Example (error)

```hcl
system "drone" {
  component "motor" {
    description = "Left motor"
  # missing closing brace
```

## Fix

Correct the HCL syntax — in this case, add the missing closing brace.

```hcl
system "drone" {
  component "motor" {
    description = "Left motor"
  }
}
```
