# E009 — Invalid port role

A `port` block's `role` attribute has a value other than `"provider"`,
`"consumer"`, or `"peer"`.

## Example (error)

```hcl
system "drone" {
  component "sensor" {
    port "data-out" {
      role = "sender"
    }
  }
}
```

## Fix

Use one of the three valid role values.

```hcl
system "drone" {
  component "sensor" {
    port "data-out" {
      role = "provider"
    }
  }
}
```
