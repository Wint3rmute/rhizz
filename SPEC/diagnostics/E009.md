# E009 — Port role not permitted by protocol

A `port` block specifies a `role` that is not declared in its referenced
`protocol`'s `roles` list, or omits `role` when the protocol requires specific roles.

## Example (error)

```hcl
protocol "docking-tunnel" {
  roles = ["active-probe", "passive-drogue"]
}

system "apollo" {
  component "csm" {
    port "docking" {
      protocol = "docking-tunnel"
      role     = "sender" # E009: role "sender" is not permitted by protocol "docking-tunnel"
    }
  }
}
```

## Fix

Use one of the roles declared on the referenced `protocol`, or add the role to the protocol's `roles` definition.

```hcl
system "apollo" {
  component "csm" {
    port "docking" {
      protocol = "docking-tunnel"
      role     = "active-probe"
    }
  }
}
```
