# W014 — Undefined protocol reference

A `port` specifies a `protocol` name, but no matching top-level `protocol`
block is defined in the project.

This is emitted as a warning (non-blocking) to allow incremental/gradual
specification before formal protocol schemas are written.

## Example (warning)

```hcl
system "drone" {
  component "controller" {
    port "spi" {
      protocol = "spi-custom"  # Warning: no protocol "spi-custom" defined
      role     = "provider"
    }
  }
}
```

## Fix

Define the top-level `protocol` block to provide structured schemas and role
validation, or correct any typo in the protocol name.

```hcl
protocol "spi-custom" {
  description = "Custom SPI protocol"
  roles       = ["provider", "consumer"]
}

system "drone" {
  component "controller" {
    port "spi" {
      protocol = "spi-custom"
      role     = "provider"
    }
  }
}
```
