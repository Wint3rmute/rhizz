# W008 — Protocol mismatch

Both sides of a connection use the typed `comp/port` syntax and both ports
declare a non-empty `protocol`, but the protocol values differ. This may
indicate a wiring mistake or a missing protocol adapter.

## Example (warning)

```hcl
system "drone" {
  component "sensor" {
    port "out" { protocol = "I2C"; role = "provider" }
  }
  component "fc" {
    port "in" { protocol = "SPI"; role = "consumer" }
  }

  connection "sensor-link" {
    from = "sensor/out"
    to   = "fc/in"
  }
}
```

`sensor/out` uses `I2C` but `fc/in` uses `SPI`.

## Fix

Ensure both ports use the same protocol, or add a protocol adapter component
between them.

```hcl
component "fc" {
  port "in" { protocol = "I2C"; role = "consumer" }
}
```
