# E021 — Delegation chain too deep

A delegation chain exceeds 1024 hops, or references an unresolvable hop.
Each hop descends one hierarchy level, so chains are bounded by nesting depth;
the cap never fires on a hand-written model and exists as a termination and
stack-safety guard for generated or pathological nesting.

## Example (error)

```hcl
component "weather-service" {
  port "api" { external = true }

  instance "proxy" { source = "reverse-proxy" }

  connection "api-delegation" {
    from = "./api"
    to   = "proxy/http"
  }
}
```

If `proxy/http` itself delegates, and so on for more than 1024 hops, the
resolver aborts with `E021`.

## Fix

Collapse the chain so the outer port delegates (transitively) to a terminal
explicit port within 1024 hops, or break the pathological nesting that
generated the depth.
