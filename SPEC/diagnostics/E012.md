# E012 — `source` exclusivity violation

An `instance` can only contain a `source` attribute, no other attributes (such
as `full_name`, `leaf`, `ports`) or child blocks. The `source` attribute means
"copy the definition from that top-level component", so additional inline
content would be ambiguous.

## Example (error)

```hcl
component "flight-controller" {
  full_name = "Main flight computer"
  leaf = true
}

system "drone" {
  instance "flight-controller" {
    source = "flight-controller"
    full_name = "Main flight computer"   # not allowed alongside source
  }
}
```

## Fix

Remove all other attributes and child blocks from the instance — keep only the
`source` attribute. Move any extra content into the top-level component
definition referenced by `source`.

```hcl
component "flight-controller" {
  full_name = "Main flight computer"
  # ports, connections, children go here …
}

system "drone" {
  instance "flight-controller" {
    source = "flight-controller"
  }
}
```
