# E012 — `source` exclusivity violation

A component that has a `source` attribute must not have any other attributes
(such as `description`, `leaf`, `ports`) or child blocks (child `component` or
`connection` blocks). The `source` attribute means "copy the definition from
that top-level component", so additional inline content would be ambiguous.

## Example (error)

```hcl
system "drone" {
  component "flight-controller" {
    source      = "flight-controller"
    description = "Main flight computer"   # not allowed alongside source
  }
}
```

## Fix

Remove all other attributes and child blocks from the component — keep only the
`source` attribute. Move any extra content into the top-level component
definition referenced by `source`.

```hcl
component "flight-controller" {
  description = "Main flight computer"
  # ports, connections, children go here …
}

system "drone" {
  component "flight-controller" {
    source = "flight-controller"
  }
}
```
