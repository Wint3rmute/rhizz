# Engineering

The **Product Engineering department** owns all technical delivery at Acme
Software. It is decomposed into three teams:

- **Frontend team** — web and mobile client engineers
- **Backend team** — API and infrastructure engineers
- **Platform team** — CI/CD, observability, and developer tooling

## Responsibilities

- Turn sprint backlogs into shipped features
- Maintain the CI/CD pipeline and developer experience
- Respond to bug reports filed by QA

## Key processes

- **Code review** — pull requests flow between the frontend and backend teams
  over the `pr-review` protocol.
- **Deploy pipeline** — the platform team provides CI/CD to the rest of
  engineering via the `cicd` protocol.
