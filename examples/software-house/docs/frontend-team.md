# Frontend Team

The **frontend team** builds and maintains the web and mobile client
applications.

## Responsibilities

- Implement product features in the web and mobile clients
- Participate in code review for all frontend changes
- Receive deployments from the platform team's CI/CD pipeline

## Interfaces

- **Code review** (`pr-review` protocol) — reviews pull requests with the
  backend team.
- **Deployments** (`cicd` protocol) — consumes deployments from the platform
  team.
