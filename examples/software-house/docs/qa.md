# QA

The **Quality Assurance department** owns testing and release approval at Acme
Software.

## Responsibilities

- File bug reports against Engineering
- Approve builds for release
- Maintain regression test coverage

## Teams

- **Manual QA** — manual and exploratory testing
- **Automation QA** — test automation engineers

## Key processes

- **Bug reports** — files bugs against Engineering over the `tickets` protocol.
- **Release sign-off** — approves releases to Product over the `release`
  protocol.
